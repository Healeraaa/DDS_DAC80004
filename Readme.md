# CV通信协议

| 字段   | 类型           | 说明         |
|--------|----------------|--------------|
| 帧头   | 0xFF             | 帧起始标志   |
| 命令   | uint8_t(0x00)    | 协议命令字   |
| 参数1  | double           | 初始电位     |
| 参数2  | double           | 终止电位     |
| 参数3  | double           | 扫描极限1    |
| 参数4  | double           | 扫描极限2    |
| 参数5  | double           | 扫描速率     |
| 参数6  | double           | 循环次数     |
| 参数7  | double(4uint8_t) | 模拟开关设置  |
| 参数8  | double           | DAC通道选择  |
| 参数9  | None             | 保留参数     |
| 参数10 | None             | 保留参数     |
| 帧尾   | 0xFE             | 帧结束标志   |

# ChannelGain 引脚定义

## WE通道选择 

| PB4 | PB3 | 通道 |
|-----|-----|------|
| 0   | 0   | WE_CHANNEL_4 |
| 0   | 1   | WE_CHANNEL_3 |
| 1   | 0   | WE_CHANNEL_1 |
| 1   | 1   | WE_CHANNEL_2 |

## IV转换增益 
| PB5 | 增益 |
|-----|------|
| 0   | 100 |
| 1   | 10000 |
## 电压放大增益
| PB7 | PB6 | 增益 |
|-----|-----|------|
| 0   | 0   | 1倍 |
| 0   | 1   | 10倍 |
| 1   | 0   | 100倍 |
| 1   | 1   | 1000倍 |

## 反馈通道选择

|-----|-----|------|
| 0   | 0   | FB_CHANNEL_4 |
| 0   | 1   | FB_CHANNEL_3 |
| 1   | 0   | FB_CHANNEL_1 |
| 1   | 1   | FB_CHANNEL_2 |
